Votre accès

Connexion au back-office

Adresse : https://frieslandv3.vercel.app/login, sur un ordinateur (Chrome conseillé).
Identifiant : votre e-mail. Le mot de passe provisoire vous est remis séparément ; il ne figure jamais dans ce guide ni dans un e-mail. À la première connexion, choisissez votre propre mot de passe.

Ce guide sert au responsable du routing de l’agence Atom. Il couvre ce que vous faites seul, sans passer par l’équipe technique : charger le routing mensuel des merchandisers, corriger une case, contrôler les tournées et suivre la couverture du mois.

Un compte administrateur
  • Votre compte a le rôle admin : c’est le seul rôle qui peut importer et corriger le routing. Il ouvre donc aussi les écrans de FrieslandCampina (utilisateurs, standards Perfect Store, référentiels).
  • Ne modifiez que ce qui concerne Atom : le routing mensuel, les alias d’import et les SSF de vos merchandisers. Pour un compte, un PDV ou un standard, adressez-vous à FrieslandCampina.
  • Mot de passe : au moins 12 caractères, trois types parmi minuscule, majuscule, chiffre et symbole, sans mot courant. Il est personnel : ne le transmettez à personne.

Les règles du routing

Ces règles sont celles du client (diapositive « Objectifs quantitatifs ») ; l’application les applique d’elle-même.

  • 10 merchandisers couvrent 4 200 PDV : 420 PDV par merchandiser et par mois, chaque PDV visité une fois par mois.
  • Chaque jour, la tournée prend un nombre de PDV par canal :
JoursSupéretteBoutiqueAboki & KiosquePushcartPorridgeTotal
Lundi à jeudi21322120
Vendredi11111115
Samedi1611110
Le quota du jour est toujours atteint
  • S’il manque une supérette, un aboki, un pushcart ou un porridge, des boutiques les remplacent.
  • Si le lieu du jour n’a pas assez de PDV, la tournée est complétée au plus près : avec les PDV du portefeuille du merchandiser les plus proches du lieu.
  • Le merchandiser ne sort pas de sa zone : il ne visite que les PDV de son portefeuille, c’est-à-dire les clients du distributeur qui lui est affecté dans le DMS.
  • Un PDV déjà visité ou déjà planifié dans le mois n’est pas repris.

Chaque nuit, l’application prépare les tournées des 7 jours suivants. Une tournée commencée n’est jamais modifiée.

Le point GPS : la façon la plus sûre de viser un lieu

Avec une latitude et une longitude, la tournée du jour prend les PDV du portefeuille du merchandiser dans le rayon autour du point. Elle ne dépend plus de l’orthographe du quartier.

  1. Dans Google Maps, faites un clic droit sur le lieu : la première ligne du menu affiche la position (ex. 5.3673, -4.0217). Un clic la copie.
  2. Collez la latitude (le premier nombre) dans Latitude et la longitude (le second, négatif à Abidjan) dans Longitude. La virgule décimale est acceptée.
  3. Laissez Rayon vide (500 m). Élargissez à 800 ou 1 000 m pour un lieu où les PDV sont peu nombreux.

Sans point GPS, le lieu est cherché par son nom dans la commune. S’il n’est pas trouvé, la tournée prend le portefeuille du merchandiser dans la commune.

Un lieu hors du portefeuille

Si aucun PDV du portefeuille du merchandiser n’est dans le rayon, le point est ignoré et la case suit la commune. Vérifiez alors le lieu, ou demandez à FrieslandCampina d’élargir son affectation DMS.

Charger le routing : simuler, puis appliquer

  1. Paramètres → Import / Export → Imports terrain → Routing mensuel des merchandisers. Choisissez le fichier.
  2. Laissez cochée la case Recalculer les tournées des 7 prochains jours.
  3. Simuler : rien n’est écrit. Le résumé et le rapport s’affichent ; ils se téléchargent.
  4. Relisez le rapport (voir ci-dessous). Une erreur se corrige dans le fichier ou par un alias, puis on simule à nouveau.
  5. Appliquer : le routing est mis à jour par lots, avec une barre de progression. Relancer le même fichier ne crée pas de doublon. Les cases d’un merchandiser qui ne sont plus dans le fichier sont désactivées.
  6. Contrôlez le résultat (chapitre « Contrôler les tournées »).

Lire le rapport

  • Résumé : merchandisers reconnus ou non, nombre de cases par point GPS, par lieu, par commune ; SSF à créer ou à relier.
  • Reconnus malgré une orthographe différente : vérifiez que chaque nom désigne la bonne personne.
  • Lieux approchés : un lieu rattaché malgré une faute ou un numéro. À relire.
  • Lieux à rattacher : le lieu n’a pas été trouvé ; la case suit la commune. Ajoutez un point GPS ou un alias.
  • Points GPS avec peu de PDV : moins de 10 PDV du portefeuille dans le rayon. La journée sera complétée au plus près ; vérifiez le point.
  • Planning par merchandiser : un tableau jour × semaine. ⊙n = point GPS avec n PDV du portefeuille dans le rayon ; ≈ = lieu approché ; ◌ = lieu non trouvé, commune ; ⚠ = ni point, ni lieu, ni commune (portefeuille entier ce jour-là).
Revenir en arrière

L’historique des imports, sous le bouton, garde chaque lot. Annuler le lot remet le routing, les règles, les quartiers des SSF et les périmètres d’avant l’import.

Corriger en cours de mois

Une case

  1. Paramètres → Référentiels → Distribution → Routing mensuel. Cherchez le merchandiser ; une ligne = un jour d’une semaine.
  2. Modifier : Point de visite, Commune, Point GPS (collez « latitude, longitude » depuis Google Maps), Rayon, SSF, Actif.
  3. Enregistrez : les règles du merchandiser et ses tournées des 7 jours à venir suivent aussitôt. La tournée du jour ne change pas.

Un nom ou un lieu mal reconnu

Alias d’import → Ajouter. Le texte du fichier tel que vous l’écrivez, le type et la cible :

  • Merchandiser : l’e-mail de son compte ;
  • SSF : le nom exact du SSF dans SSF (vendeurs) ;
  • Quartier : ZONE›QUARTIER tel qu’écrit dans les PDV (ex. ADJAME›FORUM) ; plusieurs, séparés par « | ».

Simulez ensuite à nouveau le fichier du mois. Pour un lieu, un point GPS est plus simple qu’un alias.

Contrôler les tournées

  1. Routing & Planning → Tournées planifiées, bouton Atom BTL : une ligne par merchandiser, une colonne par jour. Chaque case montre le nombre de PDV et le SSF du jour. Un clic ouvre la liste des PDV. Vérifiez qu’aucune journée n’est vide et que chaque journée a son total : 20, 15 le vendredi, 10 le samedi.
  2. Programme merchandiser South : par merchandiser et pour le mois, portefeuille, PDV planifiés, visités, objectif et reste à visiter.
  3. Écarts SSF ↔ merch : pour un jour, la tournée de chaque merchandiser comparée au routing DMS de son SSF.
  4. Versions de l’app, filtre South : qui a installé la version exigée, qui ne l’a pas encore fait.
  5. Suivi commerciaux : le trajet et les visites d’un merchandiser pour un jour donné.

Dépannage rapide

  • Une tournée n’est pas sur le bon lieu : vérifiez la case (point GPS, commune) dans Routing mensuel, puis enregistrez-la à nouveau.
  • Un jour sans tournée : la case est inactive, ou le merchandiser n’a plus de PDV à visiter ce mois-ci.
  • Un merchandiser inconnu à l’import : il n’a pas de compte, ou son nom est écrit autrement. Ajoutez un alias, ou demandez la création du compte à FrieslandCampina.
  • Un PDV manquant ou mal placé : signalez-le à FrieslandCampina avec son code.
