Votre compte agence

Se connecter

Adresse : https://frieslandv3.vercel.app/login, sur un ordinateur (Chrome conseillé). Votre identifiant est votre adresse e-mail. Le mot de passe provisoire vous est remis séparément : il ne figure jamais dans ce guide ni dans un e-mail. À la première connexion, l’application vous demande d’en choisir un.

Ce guide s’adresse au responsable du routing d’une agence (par exemple Atom BTL). Il décrit ce que vous faites seul, sans passer par l’équipe technique : charger le routing du mois de vos merchandisers, corriger une ligne en cours de mois, faire valider les tournées par vos merchandisers, contrôler les tournées et suivre la couverture du mois.

Ce que votre compte voit
  • Votre compte a le rôle Agence. Il ne voit que les merchandisers de votre agence, leurs tournées, leurs visites et leurs points de vente.
  • Vous chargez et corrigez le routing mensuel. Les tournées et les règles récurrentes, vous les consultez : elles se recalculent à partir du routing.
  • Pour un compte, un point de vente, un vendeur du distributeur (SSF) ou un standard, adressez-vous à FrieslandCampina.
  • Mot de passe : au moins 12 caractères, trois types parmi minuscule, majuscule, chiffre et symbole, sans mot courant ni votre identifiant. Il est personnel : ne le transmettez à personne. Pour le changer : votre nom, en haut à droite, puis Changer mon mot de passe.

Se repérer

Le back-office a deux niveaux de navigation : à gauche, le menu ; en haut de la page, les onglets de l’écran choisi. Le fil d’Ariane, au-dessus, rappelle où vous êtes (par exemple Planning › Programme merchandiser). Le bouton Aide, en haut à droite, ouvre ce guide.

Les règles du routing

Ces règles sont celles du client ; l’application les applique d’elle-même.

  • 10 merchandisers couvrent 4 200 points de vente : 420 points de vente par merchandiser et par mois, chacun visité une fois par mois.
  • Chaque jour, la tournée prend un nombre de points de vente par type de boutique :

Comment la tournée du jour est choisie (depuis le 20/10/2026)
  1. Les points de vente pris en compte sont ceux du fichier Atom (avec leur position GPS), quel que soit le merchandiser qui les a recensés.
  2. Le quartier d’un point de vente est le point de visite le plus proche, parmi les points de tous les merchandisers Atom.
  3. Un jour de tournée prend les points de vente du distributeur de la ligne du routing, dans le quartier de son point de visite. Exemple : Zogbolou, lundi semaine 1, Zone industrielle.
  4. S’il manque une supérette, un aboki, un pushcart ou un porridge, des boutiques les remplacent.
  5. Un jour trop court est complété avec les boutiques du même distributeur, chez le même merchandiser, dans le quartier voisin le plus proche. Jamais avec un autre distributeur.
  6. Un point de vente déjà visité ou déjà prévu dans le mois n’est pas repris.
  • Pushcarts : ils se déplacent, donc ils ne sont pas imposés par leur nom. La tournée affiche « Pushcarts 1/2 trouvés » : chaque pushcart que le merchandiser visite compte.
  • Visite libre : un jour sans point de visite dans le routing (par exemple le samedi de la semaine 4), aucun point de vente n’est imposé. Le merchandiser choisit ses points de vente ; chaque visite compte dans le quota de son type. Le planning affiche « libre 4/10 » ; dès le lendemain, un quota non atteint s’affiche en orange.
  • Un merchandiser Atom ne voit dans l’application que ses points de vente : ceux de ses tournées et ceux qu’il a créés ou visités. Une visite sur un autre magasin est refusée.

Chaque nuit, l’application prépare les tournées des 7 jours suivants. Une tournée commencée n’est jamais modifiée.

Préparer le fichier du mois

Un fichier Excel ou CSV, une ligne par jour de travail : un merchandiser, un jour, une semaine du mois (ex. Zogbolou, lundi, semaine 1). Un exemple est proposé sur la carte d’import : Télécharger un exemple de fichier. Il utilise un merchandiser fictif (« EXEMPLE Merchandiser ») : le simuler tel quel n’écrit rien.

Le point GPS du point de visite

Avec une latitude et une longitude, chaque point de vente Atom est rangé au point de visite le plus proche : c’est son quartier. La tournée ne dépend plus de l’orthographe du quartier.

  1. Dans Google Maps, faites un clic droit sur le lieu : la première ligne du menu affiche la position (ex. 5.3673, -4.0217). Un clic la copie.
  2. Collez le premier nombre dans Latitude et le second (négatif à Abidjan) dans Longitude. La virgule décimale est acceptée.
  3. Laissez Rayon vide.
Une ligne sans point GPS

Elle garde l’ancien calcul : le lieu est cherché par son nom dans la commune, avec le rayon. C’est moins sûr : un nom mal écrit ou un lieu absent donne une tournée hors du point de visite. Renseignez le point GPS de chaque ligne.

Charger le routing : simuler, puis appliquer

  1. Paramètres › Import / Export. Sur la carte Routing mensuel des merchandisers (fichier de l’agence), choisissez le fichier.
  2. Laissez cochée l’option Recalculer les tournées des 7 prochains jours.
  3. Simuler : rien n’est écrit. Le résumé et le rapport s’affichent ; ils se téléchargent.
  4. Relisez le rapport (ci-dessous). Une erreur se corrige dans le fichier ou par un alias, puis on simule à nouveau.
  5. Appliquer (le bouton rouge indique le nombre d’écritures) et confirmez. Le routing est mis à jour par lots, avec une barre de progression. Relancer le même fichier ne crée pas de doublon. Les lignes d’un merchandiser qui ne sont plus dans le fichier sont désactivées ; les merchandisers absents du fichier ne changent pas.
  6. Contrôlez le résultat (chapitre « Contrôler les tournées »).

Lire le rapport

  • Résumé : merchandisers reconnus ou non, nombre de lignes par point GPS, par lieu, par commune ; vendeurs (SSF) à créer ou à relier.
  • Reconnus malgré une orthographe différente : vérifiez que chaque nom désigne la bonne personne.
  • Lieux approchés : un lieu reconnu malgré une faute ou un numéro. À relire.
  • Lieux à rattacher : le lieu n’a pas été trouvé ; la ligne suit la commune. Ajoutez un point GPS.
  • Points GPS avec peu de points de vente : moins de 10 autour du point. La journée sera complétée par le quartier voisin ; vérifiez le point.
  • Planning par merchandiser : un tableau jour × semaine. Chaque jour dit comment le lieu a été trouvé : par point GPS (avec le nombre de points de vente autour), par un lieu approché, par la commune seule, ou ni l’un ni l’autre.
Revenir en arrière

L’Historique des imports, sous les cartes, garde chaque lot. Annuler le lot remet le routing, les règles et les périmètres d’avant l’import.

Ajouter une liste de points de vente par jour

Pour une zone, une liste de points de vente à visiter chaque jour de la semaine, en plus du routing du mois : le merchandiser fait toute la liste du jour, chaque semaine. Son routing mensuel ne change pas.

  1. Le fichier : une feuille par jour (lundi, mardi…) ou une colonne Jour. Colonnes : Nom du PDV, Localisation, Secteur, Contact, Type. Une feuille sans jour (ex. « autres ») : les points de vente sont créés, mais n’entrent dans aucune tournée. Un exemple se télécharge sur la carte.
  2. Paramètres › Import / Export, carte Liste de PDV par jour (fichier de l’agence) : choisissez le fichier, le merchandiser (si le fichier n’a pas de colonne Merchandiser) et la date de début, puis Simuler.
  3. Relisez le rapport : points de vente déjà en base (ils gardent leur GPS), créés (sans GPS), et à vérifier (un point de vente proche existe peut-être : le nom et l’adresse sont dans le tableau). Puis Appliquer.
  4. Les points de vente créés n’ont pas de position : le merchandiser les géolocalise à sa première visite, dans l’application.
Changer la liste

Un nouveau fichier pour le même merchandiser et la même zone remplace la liste d’avant. Annuler le lot remet la liste d’avant et supprime les points de vente créés qui n’ont pas encore été visités.

Corriger en cours de mois

Une ligne du routing

  1. Paramètres › Référentiels, liste Routing mensuel. Cherchez le merchandiser : une ligne correspond à un jour d’une semaine.
  2. Modifier : Point de visite, Commune, Point GPS (collez « latitude, longitude » depuis Google Maps), Rayon, Quartiers, Vendeur du distributeur (SSF), Actif.
  3. Enregistrez : les règles du merchandiser et ses tournées des 7 jours à venir suivent aussitôt. La tournée du jour ne change pas. La correction vaut jusqu’au prochain import du fichier : reportez-la aussi dans votre fichier.

Un nom ou un lieu mal reconnu

Liste Alias d’import (orthographes), puis Ajouter. Indiquez le type, le texte du fichier tel que vous l’écrivez, et la cible :

  • Merchandiser : l’adresse e-mail de son compte ;
  • Vendeur (SSF) : son nom exact, tel qu’il apparaît dans la liste des vendeurs du formulaire du routing mensuel ;
  • Point de visite : la commune, le signe ›, puis le quartier, comme sur les points de vente (ex. YOPOUGON 3›ANDOKOI) ; pour plusieurs, séparez-les par « | ». Copiez le signe › depuis l’exemple affiché sous le champ.

Simulez ensuite à nouveau le fichier du mois. Pour un lieu, un point GPS est plus simple qu’un alias.

Faire valider les tournées

Chaque mois, chaque merchandiser vérifie ses zones, ses jours et ses boutiques sur une page personnelle, ouverte par un lien que vous lui envoyez.

  1. Planning › Validation des tournées → Ouvrir la validation d’un mois.
  2. Envoyez les liens : Copier tous les liens pour un message de groupe, ou Envoyer sur WhatsApp / Copier le message par merchandiser.
  3. Suivez Retours des merchandisers : Sans réponse, Jours à corriger, Boutiques signalées, et ce que chacun propose de changer à ses zones.
  4. Pour ses zones : Retenir ces zones ou Ne rien changer à son profil. Les choix retenus s’écrivent avec Appliquer les corrections ; Annuler cette mise à jour revient en arrière.
  5. Boutiques Atom hors tournée liste les boutiques qui n’entrent dans aucun jour : à corriger dans votre fichier ou avec FrieslandCampina.
  6. Exporter les réponses (CSV) et Rapport des zones (CSV) donnent les fichiers ; Fermer ce mois termine la campagne (Rouvrir ce mois si besoin).

Un jour corrigé par un merchandiser se reporte dans votre fichier du mois suivant, ou dans Routing mensuel pour le mois en cours.

Contrôler les tournées

  1. Planning › Tournées, affichage Planning : une ligne par merchandiser, une colonne par jour. Chaque jour montre le nombre de points de vente et le vendeur du jour ; un clic ouvre la liste. Vérifiez que chaque journée a son total : 20, 15 le vendredi, 10 le samedi. Une journée affichée « libre » est un jour sans point de visite : c’est voulu. L’affichage Calendrier montre le mois d’une personne choisie dans le filtre Personne.
  2. Planning › Programme merchandiser : pour le mois et par merchandiser, ses points de vente, ceux prévus, visités, l’objectif et le reste à visiter.
  3. Planning › Écarts de tournée : pour un jour, la tournée de chaque merchandiser comparée à celle du vendeur du distributeur qui l’accompagne. « Tournée du vendeur manquante » signifie que FrieslandCampina n’a pas encore chargé le fichier de ce vendeur.
  4. Paramètres › Versions de l’app : qui a installé la version exigée, qui ne l’a pas encore fait.
  5. Carte et suivi › Suivi des équipes : le trajet et les visites d’un merchandiser pour un jour donné.

Questions fréquentes

  • Une tournée n’est pas sur le bon lieu : vérifiez la ligne (point GPS, distributeur) dans Routing mensuel, puis enregistrez-la à nouveau.
  • Un jour sans tournée : la ligne est inactive ou absente (visite libre), ou le merchandiser n’a plus de points de vente à visiter ce mois-ci.
  • Je ne peux pas modifier une tournée : c’est voulu. Corrigez la ligne du routing mensuel ; les tournées des 7 jours suivants se recalculent.
  • Un merchandiser inconnu à l’import : il n’a pas de compte, ou son nom est écrit autrement. Ajoutez un alias, ou demandez la création du compte à FrieslandCampina.
  • Un point de vente manquant ou mal placé : signalez-le à FrieslandCampina avec son nom et son code client.
  • Un message d’erreur : notez l’heure et l’écran, puis prévenez FrieslandCampina. Le détail technique est conservé pour l’équipe technique.
